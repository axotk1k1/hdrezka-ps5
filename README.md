# HDRezka for PlayStation 5

**Нативный медиаклиент для PlayStation 5 (C++ / Vulkan).**

Быстрый интерфейс в тёмной теме, рассчитанный на телевизор и полностью управляемый геймпадом DualSense. Приложение работает напрямую на консоли через Vulkan, без браузера.

> Текущая версия: **1.0.1** · Telegram: [t.me/hdrezkaps5](https://t.me/hdrezkaps5)

---

## Возможности

- **Интерфейс для телевизора** в тёмной теме, крупные элементы и плавные анимации в 1080p.
- **Анимированный баннер** на главной: популярные новинки с плавной сменой слайдов и кнопками «Смотреть» и «Мой список».
- **Каталог с фильтрацией.** Фильмы, сериалы, мультфильмы, аниме; разделы «Смотрят сейчас», «Последние поступления», «Популярное», «Новинки» и «Анонсы».
- **Расширенный поиск** по категории, жанру и году, а также поиск по стране.
- **Карточка тайтла.** Рейтинги Кинопоиск, IMDb и HDRezka; франшизы; похожие фильмы; актёры с фильмографией; расписание серий; комментарии.
- **Плеер.** Выбор озвучки, сезона, серии и качества (вплоть до 1080p Ultra / 4K при наличии Premium), субтитры, скорость, быстрая перемотка.
- **Аккаунт.** Вход, «Досмотреть» с сохранением прогресса и закладки.
- **Поиск.** Живые подсказки, история, ввод через системную клавиатуру PS5 и голосовой поиск через микрофон DualSense.
- **Обновления.** Автоматическая проверка при запуске и установка новой версии прямо из приложения («Настройки → О приложении»).

## Управление (DualSense)

| Кнопка | Действие |
|---|---|
| `D-Pad` / левый стик | Перемещение фокуса |
| `Cross (×)` | Выбор / воспроизведение / пауза |
| `Circle (○)` | Назад / закрытие окон |
| `Square (□)` | Стереть символ в строке поиска |
| `Triangle (△)` | Быстрый переход в поиск |
| `Options` | Профиль (удержание ~1 с — выход из приложения) |
| `L1` / `R1` | Слайды баннера на главной, сезоны на странице тайтла |

Закладки ставятся кнопкой с флажком на странице тайтла или кнопкой «Мой список» на баннере.

## Установка

Нужна PS5 с запущенным эксплойтом и **kstuff**.

1. Скачайте архив папки `PPSA99380` со страницы [Releases](https://github.com/axotk1k1/hdrezka-ps5/releases).
2. Скопируйте папку целиком (FTP или USB) так, чтобы получилось:
   ```
   /data/homebrew/PPSA99380/eboot.bin
   /data/homebrew/PPSA99380/sce_sys/param.json
   ```
   или `/mnt/usb0/homebrew/PPSA99380/...` на флешке.
3. Иконка появится на главном экране через ShadowMountPlus, Itemzflow или PS5 Homebrew Store. После копирования подождите 15–30 секунд или перезапустите загрузчик.

Дальнейшие обновления приложение скачивает само, после установки нужен перезапуск.
