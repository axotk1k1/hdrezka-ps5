# HDRezka for PlayStation 5

**Нативный медиаклиент для PlayStation 5.**

Удобный онлайн-кинотеатр для большого экрана, созданный специально под консоль и полностью управляемый с геймпада DualSense. Работает быстро, плавно и без использования браузера.

> Версия: **1.0.3** · Telegram: [t.me/hdrezkaps5](https://t.me/hdrezkaps5)

---

## Возможности

- **Интерфейс под ТВ:** глубокая тёмная тема, лаконичное боковое меню с современными иконками и экранная клавиатура в стиле PS5 с поддержкой сенсорной панели.
- **Полноэкранный Hero-баннер:** анимированная витрина новинок в стиле стриминговых сервисов с постерами высокого разрешения, описанием и быстрым переходом к просмотру.
- **Мгновенный запуск:** благодаря встроенному сохранению данных главная страница, постеры и списки открываются за секунду даже до ответа сервера.
- **Обширный каталог:** фильмы, сериалы, мультфильмы, аниме; разделы «Смотрят сейчас», «Последние поступления», «Популярное», «Новинки» и «Анонсы».
- **Информативные карточки:** оценки Кинопоиска, IMDb и HDRezka, список актёров, расписание выхода серий, части франшизы и блок комментариев.
- **Продвинутый плеер:**
  - Воспроизведение в качестве до 1080p Ultra и 4K без задержек и подвисаний.
  - Мгновенный выбор озвучки, сезона и серии с автоматическим обновлением списков.
  - Регулировка громкости правым стиком DualSense с экранным индикатором.
  - Двухэтапный выход из плеера (защита от случайного нажатия кнопки «Назад»).
- **Личный кабинет:** авторизация по логину и паролю, история «Досмотреть» с сохранением таймингов и синхронизация закладок.
- **Поиск:** умные подсказки на лету, история недавних запросов и голосовой ввод.
- **Обновления в один клик:** приложение само проверяет наличие свежих релизов и обновляется прямо через меню «Настройки → О приложении».

## Управление (DualSense)

### Навигация и просмотр
| Кнопка | Действие |
|---|---|
| `D-Pad` / Левый стик | Перемещение по меню и каталогу |
| `Cross (×)` | Выбрать / Воспроизведение / Пауза |
| `Circle (○)` | Назад / Закрыть окно (в плеере: первое нажатие — оверлей, второе — выход) |
| `Square (□)` | Быстро добавить или убрать из «Моего списка» (на карточке, баннере или странице) |
| `Triangle (△)` | Быстрый переход в Поиск |
| `L1` / `R1` | Переключение верхних категорий («Смотрят сейчас», «Популярное» и др.) |
| `L2` / `R2` | Переключение фильтров типов («Все», «Фильмы», «Сериалы», «Аниме») |
| Правый стик `(R3)` ↑ / ↓ | Плавная регулировка громкости в плеере |
| `Options` | Открыть профиль (удержание — выход из приложения) |

### Экранная клавиатура
| Кнопка | Действие |
|---|---|
| `Тачпад` | Перемещение курсора по клавишам касанием пальца (нажатие на тачпад — ввод) |
| `Cross (×)` | Ввод выбранной буквы |
| `Triangle (△)` | Пробел |
| `Square (□)` | Стереть символ (Backspace) |
| `L2` | Переключение регистра (Shift / Caps Lock) |
| `R1` | Смена раскладки (`РУС` / `ENG` / символы `@#:`) |
| `R2` | Готово (Enter / применить) |
| `Circle (○)` | Отмена ввода и закрытие клавиатуры |

Контекстная строка подсказок по кнопкам всегда отображается внизу экрана.
